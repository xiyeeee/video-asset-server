# Java 背景任务和素材导入开发提示词

在 `video-asset-server` 接入背景候选图任务。先读 `AGENTS.md`、任务中心、分镜导入和素材查询代码。共用契约位于同级仓库的 `../video-asset-ai/docs/background-extraction-contract.md`，按契约开发正式接口。

## 实现范围

1. 复用任务中心、自动提取、权限、步骤重试和能力开关，将 `BACKGROUND` 映射到 Python 同名分支。已有当前原视频的正式分镜时，传其已发布的 `shotManifestRef`；还没有时省略，由 Python 复用分镜检测。如本次确实通过同一 Python 任务提交分镜和背景，省略旧引用，背景使用本次结果。
2. 校验清单、同源分镜版本、相对路径、实际图片和数量，使用现有素材存储、任务事务和幂等方式导入。签名输出 JPEG 的 `imageUrl`。有确凿的同版本镜头关联时返回 `shotId`，否则返回 `null`。
3. 扩展摘要和 `GET /api/media/episodes/{episodeId}/assets?type=BACKGROUND`。按契约返回候选图、来源区间、来源时间和待复核状态。分页固定 `sourceTaskId`，失败重跑保留旧成功版。
4. 更新当前仓库的前端和部署文档。Python 有可用版本后再同步启用相应能力开关，遵守既有权限和任务日志规范。

## 本端检查

按仓库要求运行受影响模块的检查。覆盖已有关联分镜、无分镜、旧版本隔离、重复导入、非法图片引用、候选状态和分页。从契约示例完成独立测试，无需等待其他端。

## 收到通知后集中验收

用真实任务从 Java 调用 Python，导入同次生成的清单和 JPEG，通过网关读取。交接真实剧集 ID、主任务与执行 ID、素材返回和签名图片。与 Python、前端逐项核对同一集的镜头编号、来源时间和候选状态。
