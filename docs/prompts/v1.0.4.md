# 前端对接单集视频上传、集数列表和原视频预览

在 `video-asset-web` 实现项目详情页的真实单集视频功能。先检查 `AGENTS.md`、Git 状态、现有
`ProjectDetailPage`、`ProjectDialogs`、`VideoPlayer`、会话和 TanStack Query 封装。沿用项目设计和技术栈。
先完成单文件上传、刷新后的集数列表和可拖动进度条的预览。批量上传、AI 解析、小说导入和素材导出留待后续。

## 契约

复用现有 Vite 代理和登录态，统一向以下业务接口附加 `Authorization: Bearer <accessToken>`。
Gateway 本地端口为 `18080`，前端使用相对路径。响应沿用 `{code,message,data}`。

| 方法 | 路径 | 请求与响应 |
| --- | --- | --- |
| POST | `/api/media/v1/projects/{projectId}/episodes` | `FormData` 的 `file` 字段传一份 MP4，需附带 `Idempotency-Key`。成功 `201` 或幂等重试 `200`，`data` 为集数 |
| GET | `/api/media/v1/projects/{projectId}/episodes` | 可选 `page=1`、`size=20`，最大 100。成功返回 `data={items,page,size,total}`，按集号升序 |
| GET | `/api/media/v1/projects/{projectId}/episodes/{episodeId}/playback` | 授权后返回 `data={url,expiresInSeconds}`，有效期 600 秒 |

```ts
type EpisodeSummary = {
  id: string
  projectId: string
  episodeNumber: number
  title: string
  status: string
  originalFilename: string
  contentType: string
  sizeBytes: number
  durationMs: number | null
  uploadedAt: string
}
```

`id`、`projectId` 保持字符串。集号由后端分配。上传成功后为 `PENDING`（待解析）。
`durationMs` 暂缺时显示占位，播放器加载后可读取真实媒体时长。
文件上限为 100 MiB。若后端环境覆盖限制，仍按后端错误反馈实际结果。

## 实现

1. 在现有请求层增加集数 API，复用认证请求与 401 处理。上传由 Axios/浏览器生成 multipart boundary，配置足够的上传请求时限。上传进度使用真实传输进度。传输 100% 后等待服务端确认再更新集数列表。
2. 每次新选文件生成一个 UUID 作为上传键。同一文件因服务端 `5xx`、网络失败、超时或请求取消而重试时，
   保留同一键和原文件。更换文件或发起独立的新上传时生成新键。等待期间阻止重复点击。
3. 项目详情通过 TanStack Query 获取真实集数，查询键包含项目 ID 和分页参数。上传成功后失效对应列表，
   选中刚上传的集数。切换项目时清理选中集数、预览地址、进度和待上传文件。
4. 点选集数后才请求播放授权，用返回的 `url` 设置现有播放器的源。清空上一集的地址，
   避免晚到响应覆盖当前集数。播放器访问 MinIO 地址时无需携带业务 JWT。
   对签名 URL 使用接口提供的 `contentType`（如 `video/mp4`），并将播放器现有的「本机文件不会上传」
   提示限制在本地 Blob 预览。地址过期或收到可明确判定的授权失败时，重新获取签名地址。
   保留播放、暂停和拖动进度条。临时签名地址只在当前会话的短期状态中保存。
5. 区分加载、暂无集数、不可访问和读写失败。上传失败保留所选文件及重试入口。
   `400 INVALID_VIDEO` 提示检查 MP4，`413` 提示大小限制，`409` 说明文件与上传键不匹配，
   `404` 显示资源不可访问，`503` 提供带原键重试。完成后移除现有详情页里「视频上传还没有接入」的提示。

## 验收

- 登录账号 A，在自己的项目上传一份真实 MP4。接口返回待解析集数，刷新后仍能看到同一集。
- 预览能播放、暂停和拖动。切换集数后播放地址对应当前选中集。
- 模拟响应中断后用同一键重试只产生一集。无效文件、超限和 503 均有明确提示。
- 账号 B 用账号 A 的项目或集数 ID 时拿不到播放 URL，匿名请求按原有登录策略处理。
- 按前端仓库的增量检查策略执行必要验证，记录实际联调结果。
